## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `JoranBergfeld/hack-and-slice` (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. Any changes to the glossary, ADRs, or `docs/agents/` must be committed and pushed to `main` in the same session. See `docs/agents/domain.md`.
