# Workshop language

Shared terms for the Banking77 learning experience.

## Language

**Guided exercise**:
The workshop's self-directed challenges leading to a participant-trained intent classifier and a prediction for a message.

**From-scratch classifier**:
The guided exercise's intent classifier, whose parameters, including word embeddings, are learned for the exercise without a pretrained encoder.

**Demonstration message**:
A message used to show the trained classifier producing an intent, distinct from the held-out test set used for final evaluation.

**Next steps**:
Optional recommendations participants can pursue after the guided exercise without provided solutions.
